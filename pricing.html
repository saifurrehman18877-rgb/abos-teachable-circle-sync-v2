Frequently Asked Questions

Does this tool work with other platforms besides Teachable and Circle?

No, this tool is specifically designed to work with Teachable and Circle. We're exploring integrations with other platforms in the future.

How often should I run this tool?

We recommend running this tool at least once a week, or whenever you notice a spike in student churn.

Can I automate this tool?

No, this tool is static and does not support automation. However, you can set up a recurring task to run the tool manually.
